COMO LER ESTE PLACAR

Parcial não é previsão.

Os dados são lidos dos arquivos públicos do Tribunal Superior Eleitoral. A variação compara apenas a versão anterior do mesmo recorte.

Uma liderança não é resultado final. A garantia matemática exige que a vantagem supere todo o eleitorado ainda não apurado. O resultado oficial só é identificado após a conclusão nacional informada pelo TSE.
